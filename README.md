# Valuable Drop Sound
Plays the Desert Treasure II unique drop sound when you get a valuable drop.

- A drop counts as valuable when one item in it is worth at least the minimum value, 1m by default.
- Works for drops from monsters and players, and for loot from chests, caskets and raids. Chest loot needs the Loot Tracker plugin turned on.
- Also plays for new collection log items. This needs the game's collection log chat message or pop-up turned on.
- Can also play for any untradeable drop.
- Items listed under "Always play for" always play it, and items under "Never play for" never do. Names are separated by commas and * matches any text.
